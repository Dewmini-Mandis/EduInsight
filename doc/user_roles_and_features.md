User Roles & Features

1. 🏛️ National Administrator

🎯 Main Purpose

Manage the system at the national level and oversee all schools

🔹 Features

Create quizzes  
Add, update, and delete questions  
Add hints to questions  
Add correct answers  
Manage quizzes (edit / delete)  
Add and manage schools  
View national-level analytics  
Compare school performance  
Identify education gaps  
Generate large-scale reports

2. 🏫 School Administrator

🎯 Main Purpose

Manage school-level operations and monitor performance

🔹 Features

Create quizzes  
Add, update, and delete questions  
Add hints to questions  
Add correct answers  
Manage quizzes  
Add and manage teachers within the school  
Manage students  
View overall school performance  
Compare classes  
Identify weak subjects and grades  
Monitor student risk distribution  
View school-level analytics dashboards  
Generate reports (monthly / term)  
View student performance (marks, attempts, correctness)  
Identify at-risk students (AI-based risk prediction)  
View difficult lessons and topics  
View student behaviour clusters  
Track student progress over time  
Access class-level analytics dashboard  
View individual student reports  
Receive alerts for high-risk students  
Assign extra activities and exercises  
View AI-based recommended activities

3. 👨‍🏫 Teacher

🎯 Main Purpose

Monitor student performance and improve teaching strategies

🔹 Features

View student performance (marks, attempts, correctness)  
Identify at-risk students (AI-based risk prediction)  
View difficult lessons and topics  
View student behaviour clusters  
Track student progress over time  
Access class-level analytics dashboard  
View individual student reports  
Receive alerts for high-risk students  
Assign extra activities and exercises  
View AI-based recommended activities

4. 🧑‍🎓 Student

🎯 Main Purpose

Engage with learning activities and improve performance

🔹 Features

📘 Quiz Interaction

View assigned quiz list  
Start quizzes  
Answer questions  
Use hints while answering  
Update/change answers  
Navigate between questions (Next / Back)  
Submit quizzes

📊 Progress Tracking

View attempted quiz history  
View performance results  
Track progress over time

🎯 Learning Support

Identify weak areas and skills  
View recommended lessons

5. 👨‍💻 System Administrator

🎯 Main Purpose

Manage and maintain the system

🔹 Features

Manage users (all roles)  
Manage system settings  
Monitor system performance  
Handle data management and backups  
Control system access and security
